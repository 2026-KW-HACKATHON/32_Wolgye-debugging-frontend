# #65 현재 시간대 공유 요청

- 운영 시간 중에는 KST 현재 정시를 시작 시간 기본값으로 사용한다. 21:30 → 21:00~22:00.
- 오늘의 이전 시간대는 선택할 수 없다. 운영 종료 후에는 다음 공유 요일의 시작 시간을 선택한다.
- 진행 중인 시간대에 현재부터 종료까지 이용한다는 안내와 관리자 수락 조건을 표시한다.
- 사용자 확인에 따라 시간 단위 요금을 유지한다. 남은 시간이 1시간 미만이어도 선택한 시간 단위 요금이 적용됨을 안내한다.
- 열린 요청 창은 시각을 갱신하며, 전송 직전에도 만료 여부를 재검증한다.

검증: test:share-time 5개, test:reports 2개, test:parking 2개 통과. lint와 build 통과(기존 auth 동적 import 빌드 안내 유지). 임시 목 시계로 21:30의 360px 요청 화면에서 기본값/안내/이전 시간 비활성화 확인. QA 파일은 제거했다. 실제 서버 요청은 전송하지 않았다.
