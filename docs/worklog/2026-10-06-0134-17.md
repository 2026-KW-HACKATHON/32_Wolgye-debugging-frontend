# #17 화면 사용성 개선 및 브라우저 QA

- 브랜치: `feat/17-ux-ui-improvements`, 기준 커밋 `5d5e02c`.
- 이전 로컬 변경사항을 이어 검토하고 Chrome에서 목 모드로 검증했다.

## 반영된 개선

- 기본 화면은 사용자용 하단 탭으로 이동한다. 개발용 화면 목록은 `?preview=1`에서만 표시한다.
- 로그인·건물 합류·차량 등록 상태에 따라 다음 단계로 안내한다. 관리자 메뉴와 직접 주소 접근은 역할을 확인한다.
- 홈은 입체/평면 배치도와 칸별 정보, 차량 목록, 최근 알림을 보여 준다. 주차할 차량은 대표 차량을 바꾸지 않고 선택한다.
- 주차·출차 작성 내용을 차량별로 유지한다. 반복 일정 저장과 차량 관리 왕복 후 원래 화면·차량으로 돌아온다. 저장·로그아웃·새로고침 때 작성 내용을 비운다.
- 공유 요청은 공유 요일·운영 시간·지난 시각·보유 토큰에 맞춰 구체적인 안내를 표시한다. 대기 결과는 보이는 동안 15초마다 다시 확인한다.
- 알림 이동 경로를 공통 함수로 정리하고, 관리자 혼잡도는 날짜·주차 대수를 확인할 수 있게 한다. 근거 없는 고정 AI 분석 문구는 제거했다.

## 이번 QA에서 발견·수정한 문제

1. 결과 화면의 하단 돌아가기 버튼과 내 요청 목록은 검색어·필터를 잃었다. 내 요청 → 대기/수락/거절 결과 → 탐색, 수락 결과 → 위치 확인 → 탐색에서 `q`·`filter`를 유지하도록 수정했다.
2. 관리자 수락 직후 목록이 갱신되기 전에 같은 요청을 거절할 수 있었다. 실제로 `ALREADY_DECIDED` 안내가 나타났다. 대시보드·요청 목록에서 쓰기 요청과 조회 갱신이 끝날 때까지 처리 버튼을 잠그고 함수 진입도 막았다.
3. 이동 완료 화면의 돌아가기 문구를 하단 탭과 같은 "홈"으로 맞췄다. README와 기술 문서의 화면 미리보기·라우팅·입력 유지 설명도 갱신했다.
