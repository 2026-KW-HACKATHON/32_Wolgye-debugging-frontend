## 반영

1. **소개 화면(`WelcomePage`)이 목 `lotStatus`를 직접 읽지 않게 함**
   - 로그인 전이라 현황 API를 부를 수 없어서, 화면 안에 소개용 예시 칸 8개(`sampleSlots`)를 고정했다. 칸 좌표는 월계 한빛빌라 배치와 같다.
   - 이제 화면에서 `src/mocks`를 import하는 곳이 없다. 6단계(#30)에서 목을 지워도 소개 화면은 그대로 보인다.
   - 쓰는 곳이 없어진 목 `lotStatus`와 관련 import·주석을 지우고, `docs/tech-stack.md`·`docs/figma-wireframe.md`의 `lotStatus` 언급을 정리했다.
2. **`hourLabel` 중복 정리**
   - 관리자 차고지 등록(`GarageRegisterPage`)과 공유 주차(`requestPreview.ts`)에 같은 함수가 따로 있었다 → `src/pages/parking/kstTime.ts` 하나로 모으고, `requestPreview.ts`는 `todayKst`처럼 다시 내보내기만 한다. 공유 주차 화면의 import는 그대로다.
   - `todayKst()`와 `kstDate()` 중복은 이미 `requestPreview.ts`의 re-export로 하나가 되어 있었다.
3. **`TODO(logic)` 하나 정리**: 반복 일정이 없을 때 응답은 백엔드가 404로 확정(#39)해서 `src/api/parking.ts`의 TODO를 설명 주석으로 바꿨다. 남은 `TODO(logic)` 5개는 모두 목 데이터 관련이라 #30 6단계에서 목을 지울 때 같이 정리한다.
4. **새 계정이 건물 합류 전에 월계 한빛빌라를 보는 문제**: PR #37의 `App.tsx` 온보딩 안내(건물 합류·차량 등록 전 화면 접근 막기)로 해결되어 따로 고치지 않았다.
