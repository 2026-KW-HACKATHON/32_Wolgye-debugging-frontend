## 네이버 Maps 연결 (추가)

- 사용자 제공 Client ID는 로컬 `.env.local`의 `VITE_NAVER_MAP_CLIENT_ID`에 설정. `.env.example`과 `src/vite-env.d.ts`에 설정 항목 추가. Client Secret은 사용하지 않는다.
- `src/api/naverMaps.ts`: 공식 SDK를 `ncpKeyId`로 비동기 로드하고 동시에 여러 화면이 로드해도 하나의 Promise를 공유. 콜백 시 SDK의 전역 등록이 완료되도록 microtask에서 확인. 인증·스크립트 오류와 12초 시간 초과를 처리한다.
- `src/pages/shared-parking/AlleyMap.tsx`: 광운로19가길 근방을 HYBRID 위성지도로 표시 (위성사진 + 도로·지명). 4:3 가로 영역, 작은 확대·축소 버튼, 화면 크기 변경 대응 및 화면 이탈 시 정리. 실패 시 기존 사진과 재시도 버튼을 표시한다.
- 지도 중심은 제공 사진의 광운로19가길 근방으로 설정하고 실제 지도에서 현대그린빌라·비타민하우스·임오하이츠빌라 등 같은 건물명이 보이는 것을 확인. 빌라 핀은 추가하지 않았다.
- 기존 앱의 Web 서비스 URL 추가 승인을 문의했으나, 이후 코드의 초기화 순서·컨테이너 높이를 수정하여 현재 localhost에서 지도 타일 로드가 성공했다. 콘솔은 변경하지 않았다.
- 실제 서버 모드의 localhost:5173에서 360×800 위성사진·도로 라벨·공유 목록 표시, 확대(30m → 20m)와 축소(30m 복원) 확인. 지도 오류 시 기존 사진 표시도 확인.
- 배포하려면 해당 배포 환경의 Client ID 설정과 허용 Web 서비스 URL을 별도로 확인해야 한다. 배포 환경 검증은 하지 않았다.
- 참고: https://navermaps.github.io/maps.js.ncp/docs/tutorial-2-Getting-Started.html , https://navermaps.github.io/maps.js.ncp/docs/tutorial-MapTypes.html

## 남은 칸 표시를 번호 핀 위로 이동

- 사용자 요청에 따라 지도 아래 빌라명·역할·남은 칸 안내와 시연 위치 안내 영역을 제거했다.

- 조회 중·실패는 숫자 0과 구별한다. 지도 데이터의 다음 페이지가 있으면 집계된 수를 `N칸 이상`으로 표시한다. 데이터 재시도 버튼은 오류 시 지도 안에만 표시한다.
