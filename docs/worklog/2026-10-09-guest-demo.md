# 입주민·관리자 게스트 체험

- 브랜치: `feat/guest-demo` (로컬 `dev` 커밋 `859995e`에서 생성).
- 소개·로그인 화면의 ‘게스트로 체험하기’에서 입주민 또는 관리자를 선택한다. 입주민은 홈, 관리자는 관리자 대시보드로 진입한다. 체험 종료 후 다른 역할을 선택할 수 있다.
- 실제 서버 설정을 유지하고, 게스트 실행 중에만 기존 목 API를 사용한다. 공통 서버 호출 함수에서도 게스트 요청을 차단한다.
- 게스트 세션과 주차, 차량, 반복 일정, 이동 요청, 알림, 공유 요청은 실제 로그인 저장소와 별도 키로 보존한다. 관리자 요청, 공유 조건, 주차 칸 설정도 저장한다. 역할별 저장소가 독립적이며 기존 입주민 키는 그대로 유지한다. 새로고침·역할 재진입 시 복원한다. 초기화 버튼은 UI에서 제거했고 GUEST와 체험 종료 아이콘을 사용한다.
- 대기 중 공유 요청에서 ‘예시 수락 결과 보기’ 또는 ‘예시 거절 결과 보기’로 결과를 확인한다. 수락은 예시 토큰을 한 번 차감하며, 잔액과 예약 중복을 검사한다. 실제 관리자 요청을 보내지 않는다.
- 사진 제보에 예시 사진을 넣는 기능은 추가하지 않았다. 기존 사진 입력 기능은 그대로이며 사진 파일·제보 상세의 새로고침 복원은 이번 저장 범위에 포함하지 않는다.
- 차고지 상세의 상태 필터를 제거하고 모든 공유 칸을 표시한다. 칸별 상태, 요청, 배치도 선택과 목록 스크롤은 유지한다.
- 기존 홈 UI 수정과 `.env`는 보존했다. 배포 환경변수 변경이나 서버 변경은 필요하지 않다.

검증: 게스트 진입·초기화·종료, 실제 인증 저장소 분리, 서버 호출 차단, 주차·차량·프로필·일정·알림·공유 요청 재실행 복원, 중복 차감 방지, 거절 시 잔액 유지, 예약 충돌·잔액 부족에 관한 자동 테스트. 브라우저 접근은 보안 정책에서 거부되어 시각 검증은 수행하지 못했다.

관리자 확장 검증: 게스트 자동 테스트 10개 통과. 관리자 요청 처리·칸 설정·공유 조건 CRUD의 재실행 복원, 역할 간 데이터 분리, 기존 입주민 저장소 호환성, 실제 로그인 저장소 보존과 서버 호출 차단을 확인했다.
