## 로직 연결 (#16, 2026-10-04)

- auth / vehicles / sharedParking의 타입·목·API 및 화면 호출 연결 완료. 가입·로그인 검증, 건물 합류, 차량 등록·CRUD, 프로필 부분 저장, 공유 검색·필터·상세·요청·상태 결과를 처리한다.
- 조회의 로딩·오류·빈 목록, 쓰기의 중복 제출 방지와 오류 안내, 인증 만료의 로그인 이동을 제공한다.
- 요청 결과는 해시 쿼리의 요청 ID로 조회하고 `PENDING` / `APPROVED` / `REJECTED`에 맞춰 화면을 표시한다. 요청시 날짜·정시·공유 요일·최대 시간·잔액을 검증하고 토큰은 차감하지 않는다.
- 실제 HTTP와 공통 client의 401 자동 갱신·재시도는 후속 작업이다. 목 세션과 메모리 상태의 새로고침 제한, 관리자·주차 도메인 통합 잔여는 `api-layer.md` 7장을 따른다.
