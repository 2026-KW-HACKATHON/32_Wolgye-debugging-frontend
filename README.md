# 월계 디버깅 화면 디자인

Figma 와이어프레임을 바탕으로 React와 MUI로 구성한 모바일 화면 디자인입니다. 23개 페이지를 `src/pages/`에 분리했고, 공통 테마·앱 셸·배치도·상태 컴포넌트를 재사용합니다. 화면 이동, 탭 선택, 주차 칸 선택처럼 디자인 확인에 필요한 UI만 동작합니다.

```bash
npm install
npm run dev
```

브라우저의 화면 선택 메뉴에서 원하는 페이지를 고르세요. `npm run build`와 `npm run lint`로 타입·빌드·정적 검사를 할 수 있습니다. API, 실제 인증·결제·알림 전송, PWA는 포함하지 않습니다.
