# 월계 디버깅 화면 디자인

Figma 와이어프레임을 바탕으로 React와 MUI로 구성한 모바일 화면 디자인입니다. 26개 페이지를 `src/pages/`에 분리했고, 공통 테마·앱 셸·배치도·상태 컴포넌트를 재사용합니다. 화면 이동과 SVG 배치도뿐 아니라 목 API를 통해 주차·관리자·가입·설정·공유 주차 기능을 시연할 수 있습니다.

```bash
npm install
npm run dev
```

기본 화면에서는 하단 탭으로 이동합니다. 개발용 화면 선택 메뉴는 `http://localhost:5173/?preview=1#home`에서 볼 수 있습니다. `npm run build`와 `npm run lint`로 타입·빌드·정적 검사를 할 수 있습니다.

시연은 로그인 화면의 **입주민 체험 / 관리자 체험** 버튼으로 시작합니다: 입주민 `kim@kw.ac.kr`, 관리자 `admin@kw.ac.kr` (비밀번호 모두 `chagok1234`). 관리 메뉴는 관리자에게만 보입니다. 가입 후에는 건물 합류 → 차량 등록 순서로 진행하며, 건물 초대코드는 `HANBIT01`입니다.

홈에서 입체·평면 배치도를 전환하고 칸을 눌러 주차 정보를 확인할 수 있습니다. 주차할 차량은 대표 차량과 별도로 선택할 수 있고, 주차·출차 입력은 반복 일정이나 차량 관리 화면을 오가는 동안 유지됩니다. 공유 주차의 검색어·필터도 상세·요청 결과에서 돌아올 때 유지됩니다.

기본값은 목 모드입니다. 실제 서버 호출 코드는 구현되어 있으며 `VITE_USE_MOCK=false`와 `VITE_API_BASE_URL`로 전환합니다([환경 설정](.env.example)). 실제 test 서버 전체 흐름은 아직 검증 전이며, 결제·실제 알림 전송·PWA는 포함하지 않습니다. 목 데이터는 새로고침하면 초기화됩니다(세션 프로필은 유지). 범위와 제한은 [API 레이어](docs/api-layer.md), 확정 결정은 [문서 안내](docs/README.md)를 확인하세요.
