# frontend

빌라 주차 스택 관리 앱의 모바일 앱입니다.
서비스 전체 소개는 [32_Wolgye-debugging](https://github.com/2026-KW-HACKATHON/32_Wolgye-debugging)을 참고하세요.

> 서비스 한 줄 정의: 좁은 골목 빌라의 종렬 주차에서 각자 예상 출차 시간을 공유해, "내가 나갈 때 앞차가 막지 않는 자리"를 고르게 해주는 지역 한정(서울 노원구 월계1동) 앱

## 기술 스택 (미확정 항목 포함)

| 구분 | 내용 |
| --- | --- |
| 프레임워크 | React Native (Android 우선, iOS는 여력 되면) |
| 지도 | 카카오맵 또는 네이버 지도 플러그인 (빌라 위치 마커 용도, 미확정) |
| 로드뷰 | WebView 임베드, 진입 방향 확인용으로 표시만 함 |
| 주차장 레이아웃 | 위에서 내려다보는 2D 뷰를 직접 렌더링 (지도 SDK 사용 안 함) |
| 알림 | Firebase Cloud Messaging (FCM) |

## 주요 화면 (MVP)

1. 
2. 주차장 레이아웃: 칸마다 상태 색상 표시
3. 입차 등록: 칸 선택 + 예상 출차 시간 입력
4. 자리 추천: 안전한 칸 표시, 막히는 칸 경고
5. 알림 수신 (앞차 출차 임박, 내 차가 막고 있음, 이동 요청)
6. 이동 요청 보내기 (전화번호 노출 없음)
7. 미등록 차량 등록 ("출차 시간 미상")

## 개발 원칙

- API 키를 앱에 하드코딩하지 않습니다. LLM 호출은 백엔드를 경유합니다.
- 로드뷰 이미지를 저장하거나 가공하지 않습니다 (지도사 약관 위반 소지).
- 칸 확정은 사용자가 직접 선택합니다 (GPS 오차 5~10m로 칸 판별 불가).
- 실시간 갱신은 FCM 데이터 메시지와 앱 포그라운드 진입 시 재조회로 처리합니다 (SSE/WebSocket 사용 안 함).
- 차량번호는 마스킹해서 표시합니다 (예: `12가 ****`).
