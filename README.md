# 월계 디버깅 화면 디자인

Figma 와이어프레임을 바탕으로 React와 MUI로 구성한 모바일 화면 디자인입니다. 26개 페이지를 `src/pages/`에 분리했고, 공통 테마·앱 셸·배치도·상태 컴포넌트를 재사용합니다. 화면 이동과 SVG 배치도뿐 아니라 목 API를 통해 주차·관리자·가입·설정·공유 주차 기능을 시연할 수 있습니다.

```bash
npm install
npm run dev
```

브라우저의 화면 선택 메뉴에서 원하는 페이지를 고르세요. `npm run build`와 `npm run lint`로 타입·빌드·정적 검사를 할 수 있습니다. 실제 서버 인증·결제·알림 전송·PWA는 포함하지 않습니다. 시연은 체험 계정 `kim@kw.ac.kr` / `chagok1234` 로그인부터 시작합니다. 주차 화면은 로그인한 사용자의 차량을 씁니다, 건물 초대코드는 `HANBIT01`입니다. 목 데이터는 새로고침하면 초기화됩니다(세션 프로필은 유지). 범위와 제한은 [API 레이어](docs/api-layer.md), 확정 결정은 [문서 안내](docs/README.md)를 확인하세요.
